# MANGO BLOCK 腳位介紹

> 這份文件是參考資料，**不用實作**。想知道某個接頭接到哪一支腳、之後想自己接東西時再來查。

## 先懂兩件事

**1. 每個元件都接在晶片的一支腳（GPIO）上。** 程式要指定「哪一支腳」才能控制它。

**2. 名字和號碼是同一支腳。** 課程韌體幫每支腳取了名字，用名字比較好讀、不容易寫錯：

```python
from machine import Pin

Pin("KEY1")   # 和 Pin(30) 是同一支腳
Pin(30)
```

腳位有兩種基本用法：

| 用法 | 寫法 | 例子 |
|---|---|---|
| 輸出：程式「送出」 | `Pin("名字", Pin.OUT)` | 控制燈、蜂鳴器 |
| 輸入：程式「讀進」 | `Pin("名字", Pin.IN, Pin.PULL_DOWN)` | 讀按鈕（按下 = 1） |

## 上午用到的腳

| 名字 | GPIO | 接到 | 怎麼用 |
|---|---|---|---|
| `WS2812B` | 45 | 板子上的 6 顆彩燈 | `neopixel.NeoPixel(Pin("WS2812B"), 6)` |
| `BUZZER` | 46 | 蜂鳴器 | `PWM(Pin("BUZZER"))`，`freq` = 音高、`duty_u16` = 音量 |
| `KEY1` | 30 | 按鍵 1 | `Pin("KEY1", Pin.IN, Pin.PULL_DOWN)`，按下 = 1 |
| `KEY2` | 31 | 按鍵 2 | 同上 |

## 下午用到的腳（舵機實作）

| 名字 | GPIO | 接到 | 說明 |
|---|---|---|---|
| `SS_TX` | 8 | SS1 / SS2 接頭 | UART1 送出：送封包給匯流排舵機 |
| `SS_RX` | 9 | SS1 / SS2 接頭 | UART1 讀回：讀舵機的回覆 |

匯流排舵機用一條線串很多顆，用「封包 + ID」指定要控制哪一顆，速度是 115200 baud。詳細內容看下午的舵機實作。

## 其他接頭（參考）

### 直流馬達（DRV8870 驅動）

| 名字 | GPIO | 接頭 |
|---|---|---|
| `M1A` / `M1B` | 0 / 1 | M1 |
| `M2A` / `M2B` | 2 / 3 | M2 |
| `M3A` / `M3B` | 4 / 5 | M3 |
| `M4A` / `M4B` | 6 / 7 | M4 |

每個馬達用兩支腳（A、B），用 PWM 控制轉速和方向。

### 馬達編碼器

| 名字 | GPIO | 接頭 |
|---|---|---|
| `EC1A` / `EC1B` | 12 / 13 | EM1 |
| `EC2A` / `EC2B` | 14 / 15 | EM2 |
| `EC3A` / `EC3B` | 16 / 17 | EM3 |
| `EC4A` / `EC4B` | 18 / 19 | EM4 |

### 通訊介面

| 名字 | GPIO | 用途 |
|---|---|---|
| `I2C0_SDA` / `I2C0_SCL` | 26 / 27 | I2C0 排針（感測器、螢幕） |
| `I2C1_SDA` / `I2C1_SCL` | 10 / 11 | I2C1 接頭 |
| `SPI_RX` / `SPI_CS` / `SPI_CLK` / `SPI_TX` | 20 / 21 / 22 / 23 | SPI（外部 SPI 裝置） |
| `UART_TX` / `UART_RX` | 28 / 29 | UART0 上位機排針 |

### 擴充排針

| 名字 | GPIO | 說明 |
|---|---|---|
| `P1` ~ `P5` | 40 ~ 44 | 3 Pin 排針（GND / VCC / 訊號），可當一般 GPIO、PWM，P1~P5 也能讀類比電壓（ADC） |
| `TFT_BL` / `TFT_CS` / `TFT_DC` / `TFT_RST` | 32 / 33 / 34 / 35 | TFT 螢幕排針 |

### 不要使用的腳

| GPIO | 原因 |
|---|---|
| 36 ~ 39 | 接到 RM2 無線模組（藍牙、Wi-Fi），被韌體佔用 |
| 47 | PSRAM 用（有些板子沒有裝） |

> 原廠資料上還有 IMU（BMI270）、麥克風、OLED 等元件，課程用的板子不一定有裝。
