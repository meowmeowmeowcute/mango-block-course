# 上午：認識 MANGO，做出藍牙網頁儀表板

```
 認識板子 ─► LED & 按鈕 ─► 蜂鳴器 & pin 腳 ─► 網頁儀表板實作
   01         02 ~ 03        04、PINS.md      project/
```

今天的目標是**用程式控制這塊板子**。每支範例只教一個觀念，最後的網頁儀表板實作會把這些觀念全部用上。

還沒裝好環境的話，請先看[根目錄的說明](../README.md)。

## 範例（`examples/`）

在 VS Code 打開檔案 → 按狀態列的 **Run**。每支程式開頭都有說明和「動手改改看」的練習題。

| 檔案 | 學什麼 | 儀表板會用在 |
|---|---|---|
| `01_hello_mango.py` | 確認環境裝好了 | — |
| `02_led.py` | 彩燈：`np[i] = (R, G, B)`，要 `np.write()` 才會送出；for 迴圈控制 6 顆燈；跑馬燈動畫 | TODO 1、4、5、6 |
| `03_button.py` | 按鈕：`.value()`，按下 = 1；按住才亮、按一下切換（去彈跳） | TODO 2、7 |
| `04_buzzer_melody.py` | 蜂鳴器：`freq` = 音高、`duty_u16` = 音量；把歌譜存在串列裡，播一首歌 | TODO 3 |

板子上每個接頭接到哪一支腳，請看 [`PINS.md`](PINS.md)（參考用，不用實作）。

### 常見錯誤

| 現象 | 原因 |
|---|---|
| 燈不亮 | 忘了寫 `np.write()` |
| 出現 `TypeError` | 顏色用到小數了，要用 `int()` 轉成整數 |
| 按 Stop 之後燈還亮著、蜂鳴器還在響 | 沒有在 `finally` 裡關燈、關蜂鳴器 |
| 按一下就切換好幾次 | 沒有去彈跳，或沒有判斷「0 → 1 的那一瞬間」 |
| 按鈕一直讀到 0 | 忘了 `Pin.PULL_DOWN`，或寫成了 `Pin.OUT` |

## 網頁儀表板實作（`project/`）

```
   瀏覽器（已完成）                     MANGO X4 板子
 ┌──────────────┐   藍牙    ┌──────────────────┐        ┌───────────────────┐
 │ 網頁儀表板     │ ───────► │ mango_ble.py      │ 呼叫 ─► │ dashboard.py      │
 │ 按鈕、滑桿、琴鍵 │          │ 工具庫（已完成）   │        │ ★ 你寫的函式       │
 │ 按鍵燈、小遊戲  │ ◄─────── │ 處理所有藍牙的事    │ ◄───── │ on_led、read_keys… │
 └──────────────┘          └──────────────────┘        └─────────┬─────────┘
                                                                   ▼
                                                         彩燈、蜂鳴器、按鍵
```

**網頁上按下按鈕 → 板子上「你寫的某個函式」就會被呼叫。**
你只要完成 `project/board/dashboard.py` 裡的 TODO，網頁和藍牙的部分都已經做好了。
做完之後也可以自由修改網頁、加新功能——每個檔案開頭都有結構說明。

### 開始

1. 在 `project/board/mango_ble.py` 上按右鍵 → **Upload File to Board**（只要做一次）。
2. 打開 `project/board/dashboard.py` → 按 **Run**。終端機會出現：

   ```
   📡 等待網頁連線…  我的名字是： MANGO-XXXX
   ```

   **記下自己板子的名字**，教室裡有很多塊板子。

3. 在 VS Code 開一個新的終端機（上方選單 Terminal → New Terminal），依序輸入：

   ```bash
   cd morning/project/web
   ```

   ```bash
   python -m http.server 8000
   ```

4. 用 Chrome 或 Edge 打開 <http://localhost:8000> → 按「連線」→ 選**自己的** MANGO-XXXX。
5. 改完程式之後：**Stop → Run → 網頁再按一次「連線」**。

> 為什麼不能直接雙擊打開 `index.html`？因為瀏覽器只允許 `https` 或 `localhost` 的網頁使用藍牙。

**自由發揮**：想改網頁或加新的藍牙功能，先看 `board/mango_ble.py` 最上面的「怎麼新增一個功能」。
可以用 VS Code 內建的 AI Agent 一起做：描述想法 → 大致理解程式與重要觀念 → 除錯、重新定義需求，一圈一圈改到滿意。

**小技巧**：終端機會印出 `[網頁] on_led(255, 255, 0, 0)` 這樣的訊息，告訴你網頁呼叫了哪個函式、傳了什麼值。
有問題時先看這裡！

### 常見問題

| 現象 | 原因／解法 |
|---|---|
| `ImportError: no module named 'mango_ble'` | `mango_ble.py` 還沒上傳到板子（見「開始」第 1 步） |
| 按「連線」沒有跳出選單 | 不是用 `localhost` 開啟的；或瀏覽器不是 Chrome／Edge；或電腦的藍牙沒有打開 |
| 選單裡找不到自己的板子 | `dashboard.py` 沒有在執行；或被別人連走了，請對照終端機印出的名字 |
| 網頁操作了，板子卻沒反應 | 看終端機：有 `[網頁] ...` 代表網頁有送到，是你的函式要修改；有 `⚠ 你的 on_led 出錯了` 就照錯誤訊息修改 |
| 跑馬燈、呼吸燈都是黑的 | 這兩個效果使用 `colors` 的顏色，請先用「全部彩燈」設定一個顏色 |
| 改了程式卻沒有效果 | 要 Stop → Run，網頁也要重新連線 |
| 找不到 `python` 指令 | 安裝 Python 時沒有勾選 Add to PATH。重新安裝，或改用 `py -m http.server 8000` |
