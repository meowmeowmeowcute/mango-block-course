# 下午：Hiwonder 匯流排舵機

今天的目標是**用程式控制三顆 Hiwonder 匯流排舵機**：先接好一顆、讀到它的狀態、讓它轉，再把三顆串起來一起轉，最後寫自己的程式。

還沒裝好環境、還沒燒錄韌體的話，請先看[根目錄的說明](../README.md)。

---

## 要準備的東西

- MANGO BLOCK 開發板、可以傳資料的 USB Type-C 線
- Hiwonder 45 kg·cm 匯流排舵機 × 3，舵機串接線 × 3
- 12V 電源和 XT30 供電線（USB 推不動舵機）

> 注意!
> 改接線之前，先關外接電源（POWER_SW 撥到 OFF）
> 舵機固定好、手離開，再讓它轉。45 kg·cm 夾到手很痛的
> 小角度、慢速地轉，讀到亂碼或雜訊時，不要送移動指令

---

## 檔案

| 檔案 | 怎麼用 | 做什麼 |
|---|---|---|
| `servo.py` | 右鍵 → **Upload File to Board**（只要做一次） | 舵機的工具庫，提供下面的指令 |
| `scan.py` | 打開 → **Run** | 找出線上的舵機，檢查 ID，印出電壓、位置、溫度 |
| `example.py` | 打開 → **Run** | 範例：三顆輪流轉一點再轉回來 |
| `play.py` | 打開 → 寫程式 → **Run** | 你自己的程式 ! |

上傳 `servo.py` 之後，在 vREPL 或程式裡先打 `from servo import *`，就能使用：

| 指令 | 做什麼 | 範例 |
|---|---|---|
| `move(id, 位置, 毫秒)` | 轉到指定位置（0–1000 = 0–240°） | `move(1, 600, 2000)` 2 秒轉到 600 |
| `pos(id)` | 讀現在的位置 | `pos(1)` → `560` |
| `vin(id)` | 讀電壓，單位 mV | `vin(1)` → `12121` |
| `beep(n)` | 蜂鳴器響 n 聲 | `beep(2)` |
| `send(id, cmd, 參數)` | 直接送一個封包，回傳原始回覆 | `send(1, 27)` |

## 1. 接線

1. 插上 Type-C，板子開機，VS Code 連上。
2. 舵機線**用完整的接頭**插進 **SS1**，插到底。（SS2 是另一種規格，插不進去是正常的）
3. XT30 接上 12V 電源，POWER_SW 先保持 **OFF**。
4. POWER_SW 撥到 **ON**。

## 2. 先讀，不要轉

打開 `scan.py` → **Run**。它只會讀取，舵機不會動。

```
found id 1 reply 55 55 01 05 1C E8 03 F2
  ok  vin 12121 mV, pos 1000, temp 31 C
found: [1]
```

| 結果 | 意思 | 怎麼辦 |
|---|---|---|
| `ok` | 這個 ID 只有一顆，回覆乾淨 | 記住這個 ID，可以開始轉了 |
| `overlap?` | 回覆有亂碼，可能兩顆舵機同一個 ID | 見「4. 改 ID」 |
| `unstable` | 回覆時有時無 | 接頭沒插好，關電重新插 |
| 什麼都沒找到 | 舵機沒電或沒接好 | 檢查 XT30、POWER_SW、SS1 接頭 |

## 3. 讓一顆轉

在 vREPL 一行一行輸入（ID 換成你在 `scan.py` 看到的）：

```python
from servo import *
pos(1)              # 先知道它停在哪裡，例如 560
move(1, 600, 2000)  # 2 秒轉到 600，手先離開
pos(1)              # 確認到了，差一點點是正常的
```

### 封包長什麼樣子？

每個指令都會變成一串位元組送出去：

```
55 55  01  07  01  F4 01 E8 03  16
開頭   ID  長度 指令 參數          校驗
           (參數+3) (1=移動) (位置 500、時間 1000 ms，低位元組在前)
```

校驗 = `~(ID + 長度 + 指令 + 參數) & 0xFF`。舵機只回應 ID 跟自己一樣的封包。

## 4. 改 ID

三顆舵機串在同一條線上，**每顆的 ID 都要不一樣**（目標：1、2、3）。出廠時通常都是 1。

1. 關電，線上**只留一顆**要改的舵機（ID 不同的可以留著）。
2. 開電，跑 `scan.py`，確認這個 ID 是 `ok`。
3. 在 vREPL 送出改 ID，例如把 3 改成 1：

   ```python
   from servo import send
   send(3, 13, bytes([1]))   # 回傳 b'' 是正常的，改 ID 不會回覆
   ```

4. 再跑一次 `scan.py`，看到新的 ID 就改好了。在舵機上貼標籤。

> 線上只有一顆時，也可以用廣播直接問它的 ID：`send(254, 14)[5]`

## 5. 三顆一起轉

先 `from servo import *`，在 vREPL 輸入：

| 指令 | 做什麼 |
|---|---|
| `move(2, 600, 1000)` | 只有 ID 2 會動 |
| `for i in (1, 2, 3): move(i, 600, 2000)` | 三顆一起轉到 600 |
| `for i in (1, 2, 3): move(i, 500, 2000)` | 三顆一起回中間 |
| `[pos(i) for i in (1, 2, 3)]` | 讀三顆的位置 |

`for` 那兩行打完要**按兩次 Enter** 才會執行。

## 6. 寫自己的程式

先打開 `example.py` 然後 **Run**：三顆輪流朝中間轉一點、再轉回來，響幾聲就是幾號在轉。
檔案最上面有三個數字可以改：

| 數字 | 意思 |
|---|---|
| `SERVO_COUNT = 3` | 轉幾顆（ID 1 到 3） |
| `OFFSET = 50` | 轉多少，50 大約 12° |
| `MOVE_MS = 1000` | 轉一次花幾毫秒 |

接著換你寫 `play.py`。挑戰：

- 讓一顆舵機來回擺 3 次
- 三顆同時轉
- 按 KEY1 才轉

> 不要把自己的程式存成 `main.py` `main.py` 開機會自動執行
