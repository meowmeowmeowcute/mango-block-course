# MANGO BLOCK 課程韌體

`MANGO_BLOCK-v1.29.0.uf2`：MicroPython v1.29.0，加上 MANGO BLOCK 的藍牙／Wi-Fi 支援，以及板上元件的腳位名稱。

## 燒錄方法

1. 用 USB 線接上板子。
2. **按住 BOOT 鍵 → 按一下 RESET 鍵 → 放開 BOOT 鍵**，電腦會出現一個名叫 `RP2350` 的磁碟。
3. 把 `MANGO_BLOCK-v1.29.0.uf2` 拖進這個磁碟，磁碟自動消失就完成了。

燒錄不會清掉板子上原本存的檔案。

## 腳位名稱

程式裡可以直接用名稱，例如 `Pin("KEY1")`，不用記 GPIO 編號。

| 名稱 | GPIO | 接到 |
|---|---|---|
| `WS2812B` | 45 | 6 顆彩燈 |
| `BUZZER` | 46 | 蜂鳴器 |
| `KEY1`、`KEY2` | 30、31 | 按鍵（下拉，按下 = 1，要用 `Pin.PULL_DOWN`） |
| `M1A`、`M1B` … `M4A`、`M4B` | 0 ~ 7 | 馬達 1 ~ 4 |
| `EC1A`、`EC1B` … `EC4A`、`EC4B` | 12 ~ 19 | 馬達編碼器 1 ~ 4 |
| `P1` ~ `P5` | 40 ~ 44 | P1 ~ P5 排針 |
| `I2C1_SDA`、`I2C1_SCL` | 10、11 | I2C 接頭 |

GPIO 36 ~ 39 已經被藍牙／Wi-Fi 模組使用，不要在程式裡使用。
